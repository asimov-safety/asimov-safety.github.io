A guided local interface

Meet Asimov
Studio.

Run an Asimov assessment without hand-editing JSON. Studio turns the same portable assessment files into a guided local workflow for scope, testing, human review, signing, and verification.

Launch Studio ↓
Same engine. Better interface.

Studio does not replace the Asimov protocol. It makes the existing protocol easier to use.

What Studio does

From empty folder to verifiable assessment.

Create or reopen a workspace

Choose the assurance level, adapter, assessor, and organizations. Studio writes the ordinary Asimov assessment files—not a private database.

Define scope in plain language

Describe the deployment, threat model, and explicit exclusions in forms instead of editing scope.json.

Check readiness and run the tests

Studio uses the same fail-closed readiness diagnostics and technical probes as the command line.

Complete human review

HUMAN, ROLE_SEPARATED, and THIRD_PARTY review records become guided forms with evidence checklists, rationale, independence declarations, and reviewer signing.

Finalize, sign, and verify

Build the report, authenticate reviewer judgments and report provenance with Sigstore, and verify the complete package locally.

Install and launch

One command opens the app.

Asimov Core is language-neutral. The current reference implementation and Studio require Python 3.10 or newer.

macOS

Install the current open-source reference implementation:

python3 -m pip install "https://github.com/asimov-safety/asimov/archive/refs/heads/main.zip"

asimov studio
Windows

From PowerShell with Python 3.10+ installed:

py -m pip install "https://github.com/asimov-safety/asimov/archive/refs/heads/main.zip"

asimov studio
Linux

Install directly from the public GitHub repository:

python3 -m pip install "https://github.com/asimov-safety/asimov/archive/refs/heads/main.zip"

asimov studio

Already have an assessment?

Open it directly. Studio reads the existing portable workspace rather than importing it into a new format.

asimov studio --workspace ./assessment

Prefer the source repository?

Clone the project, install it editable, and launch Studio from the same checkout used for the CLI.

git clone https://github.com/asimov-safety/asimov.git
cd asimov
python -m pip install -e .
asimov studio

Local first

Your assessment stays on your machine.

Studio binds only to 127.0.0.1, uses a random session token on every launch, enables no CORS access, and requires no Asimov account or hosted project.

No lock-in

Studio and the CLI use the same files.

Start in Studio, continue from the command line, hand the folder to an independent reviewer, or implement the published protocol in another language. The workspace remains the source of truth.

Rigorous assessment should not require loving JSON.
