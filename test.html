Bring your
own stack.

Asimov sits above frameworks and vendors. A thin adapter translates your existing controls into the standard’s semantic test operations.

Install Asimov

Start in a clean Python 3.10+ environment and validate the reference harness.

git clone https://github.com/asimov-safety/asimov.git
cd asimov
python -m pip install -e .

asimov reference-probes
asimov reference-mutations

Map the real architecture

Identify the action driver, authority source, resource oracle, lifecycle controller, supervisor, and evidence source that already exist in your deployment.

Build the adapter

Translate native infrastructure into Asimov semantics. The adapter may connect controls; it must not invent controls the deployment does not have.

Run readiness and conformance

Missing mandatory surfaces block the requested level. Once the deployment is ready, execute the same semantics against the real system.

asimov doctor --level A5
